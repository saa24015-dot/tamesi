Firebase 連携設定

ご自身のFirebaseコンソールの「プロジェクト設定」から取得した設定情報を入力すると、本アプリがご自身のCloud Firestoreと接続されます。

GitHub Pagesで動作させる場合は、Firebaseコンソールの [Authentication] -> [設定] -> [承認済みドメイン] にご自身のGitHub Pagesドメインを追加してください。
